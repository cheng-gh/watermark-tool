# חותמת — כלי להוספת סימן מים לתמונות

כלי וובי קל, פרטי ומותאם למובייל להוספת לוגו או סימן מים לתמונות.

## תכונות

- העלאת תמונה ולוגו ישירות מהמכשיר
- סימן מים יחיד או דפוס חוזר
- שליטה בגודל, שקיפות, מרווח ומיקום
- גרירת הלוגו ישירות על התמונה
- שמירת הלוגו וההגדרות בדפדפן לשימוש הבא
- מצב יצירה מהירה: כל תמונה חדשה מעובדת ויורדת אוטומטית
- ייצוא ל-JPG, PNG או WEBP
- ממשק עברי RTL בגישת Mobile First
- תמיכה ב-iPhone וב-Android
- אפשרות התקנה במסך הבית כ-PWA
- עיבוד מקומי בלבד — התמונות והלוגו אינם נשלחים לשרת

## הפעלה מקומית

אפשר לפתוח את `index.html` ישירות, אך לצורך PWA ומטמון אופליין מומלץ להפעיל שרת מקומי:

```bash
python -m http.server 4173
```

ואז לפתוח `http://localhost:4173`.

## פרסום

זהו אתר סטטי ללא תהליך build. אפשר לפרסם את תוכן המאגר ישירות באמצעות Cloudflare Pages, Netlify או GitHub Pages.

יש לפרסם יחד את:

- `index.html`
- `styles.css`
- `app.js`
- `sw.js`
- `manifest.webmanifest`

## שימוש בטלפון

### iPhone

פותחים את האתר ב-Safari, לוחצים על שיתוף ובוחרים **הוספה למסך הבית**.

### Android

פותחים את האתר ב-Chrome ובוחרים **התקנת אפליקציה** או **הוספה למסך הבית**.

## פרטיות

כל עיבוד התמונה מתבצע ב-Canvas בתוך הדפדפן. הלוגו וההגדרות נשמרים מקומית באמצעות IndexedDB ו-localStorage. אין העלאה של תמונות לשרת.
